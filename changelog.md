## 3.0.0 - 2026-03-20
* The SDK now supports HTTP request/response logging for debugging purposes and accepts multiple files for Lab Report parsing. The AppointmentPscLabs enum adds support for Sonora Quest as a new provider option.
* New optional parameters added to lab test and appointment methods including lab account filtering, appointment notes, clinical notes, and idempotency support for PSC appointment booking.
* New optional parameters added to lab test and appointment APIs including lab filtering by slug and account ID, appointment notes, idempotency support for PSC bookings, clinical notes for orders, and SDK version tracking for manual provider connections. The PSC appointment availability method now requires a lab parameter instead of using a hardcoded value.
* The SDK now includes new client modules for compendium search, lab account management, and order transaction handling. The user creation methods now accept a `UserAddress` type instead of `Address` for improved address handling. Additional types have been added to support enhanced lab testing workflows and order management capabilities.
* New CompendiumClient and LabAccountClient available. The CompendiumClient provides search() and convert() methods for lab test operations across different providers. The LabAccountClient offers get_team_lab_accounts() for retrieving team lab account information. Both clients support async operations.
* New OrderTransactionClient provides methods to retrieve order transaction details, results, and PDF reports. Enhanced link provider methods now support optional mobile SDK version headers and granted permissions configuration.
* The SDK now supports appointment notes during booking and rescheduling, asynchronous appointment confirmation with configurable timeouts, and order transaction tracking. Lab compendium search functionality is available with new types for canonical candidates and provider conversions. Sonora Quest is now supported as a lab provider and appointment provider.
* The SDK now supports enhanced lab testing workflows with new order transaction tracking, compendium conversion capabilities, and derived readiness data analysis. Additional providers are now supported including Samsung Health and Tandem Source.
* The SDK now supports compendium search functionality with new types including RelatedCandidate, SearchCompendiumResponse, and SearchMode. Additionally, new enums ResultMetadataGender and UsState are available with forward compatibility for unknown values. Address handling is enhanced with a new UserAddress model and access_notes field added to UsAddress for delivery instructions.
