## 2.2.0 - 2026-03-18
* The SDK now includes comprehensive HTTP request logging capabilities with configurable log levels and automatic header redaction for sensitive data. Lab report parsing methods now accept multiple files instead of a single file. The AppointmentPscLabs type has been expanded to include Sonora Quest support.
* The SDK now supports additional optional parameters for more granular control over lab operations. New parameters include lab filtering options (lab_account_id, lab_slug), appointment booking enhancements (appointment_notes, idempotency support), and order management improvements (order_transaction_id, clinical_notes filtering).
* The SDK now supports additional filtering and configuration options for lab tests, including lab_account_id and lab_slug parameters for test creation and marker retrieval. New appointment booking features include appointment notes and idempotency key support to prevent duplicate PSC appointments. Manual provider connections now accept SDK version parameters and granular permission settings for enhanced integration capabilities.
* New compendium, lab account, and order transaction client modules are now available. The address parameter in user creation methods now uses the enhanced UserAddress type for improved address handling capabilities.
* New `CompendiumClient` and `LabAccountClient` modules are now available. The `CompendiumClient` provides `search()` and `convert()` methods for lab test operations, while the `LabAccountClient` offers `get_team_lab_accounts()` for team lab account management. Both clients support async operations and raw response access.
* The SDK now supports order transaction operations through new OrderTransactionClient with methods to retrieve transaction details, results, and PDF reports. Additionally, link connection methods now accept optional mobile SDK version tracking parameters for iOS and Android platforms, and support granted permissions tracking.
* The SDK now supports enhanced appointment booking with appointment notes and asynchronous confirmation options, lab compendium search and conversion APIs for discovering and mapping lab tests across providers, and team-level lab account management. Sonora Quest is now available as a supported lab and appointment provider.
* The SDK now supports derived readiness data querying, expanded lab testing providers (Sonora Quest, CRL), Samsung Health integration, and enhanced lab account management capabilities. New types include order transaction tracking, provider ID conversion, and parsing job failure handling.
* New `UsState` enum and `UserAddress` type are now available for handling US state information and complete address data.
