## 2.2.0 - 2026-03-24
* The SDK now includes comprehensive logging and debugging capabilities. Configure logging when initializing clients to automatically log HTTP requests and responses, with automatic redaction of sensitive headers. The BaseHttpResponse class now exposes a status_code property for easier debugging. Lab report parsing now supports uploading multiple files at once. Added support for Sonora Quest lab appointments through the enhanced AppointmentPscLabs enum.
* The SDK now supports additional filtering and customization options for lab tests and appointments. New optional parameters include lab account filtering, transaction-based order filtering, appointment notes, clinical notes, and idempotency support for PSC appointment booking. The get_psc_appointment_availability method now requires a lab parameter and supports stale data caching.
* New optional parameters added for enhanced lab test and order management: lab_account_id and lab_slug for lab test creation, order_transaction_id filtering for orders, appointment_notes for appointments, and clinical_notes for order creation. PSC appointment booking now supports idempotency with idempotency_key and idempotency_error headers. Manual provider connection enhanced with vital_ios_sdk_version, vital_android_sdk_version, and granted_permissions parameters.
* The SDK now supports three new client modules: CompendiumClient for searching and converting lab test compendium data, LabAccountClient for managing team lab account configurations, and OrderTransactionClient for handling order transaction operations. The user registration methods now use UserAddress instead of Address for improved API consistency.
* New compendium client available for searching and converting lab tests between providers. New lab account client enables retrieval of team lab account information.
* New OrderTransactionClient and LabAccountClient modules are now available. The OrderTransactionClient provides methods to retrieve transaction details, results, and download PDF reports. The LabAccountClient enables management of team lab accounts. Additionally, the link client's connect_manual_provider method now supports mobile SDK version headers and granted permissions tracking.
* The SDK now supports lab account management through new lab account APIs, compendium search for lab test discovery, and order transaction tracking. Appointment booking now includes asynchronous confirmation options and support for the Sonora Quest provider. Lab report parsing job webhooks are available for real-time processing updates.
* New types and capabilities added for derived readiness analytics, expanded lab testing functionality, and additional provider integrations. The SDK now supports Samsung Health and Tandem Source providers, enhanced order transaction management, and additional lab testing providers including Sonora Quest and CRL.
* The SDK now supports compendium search functionality with new models for search results, candidates, and related data. Added comprehensive US state enumeration and generic address handling. The UsAddress model now includes an optional access_notes field for delivery instructions.
