## 3.0.0 - 2026-03-31
* The SDK now supports comprehensive HTTP request/response logging with automatic redaction of sensitive headers. New SONORA_QUEST appointment lab provider added to AppointmentPscLabs. The BaseHttpResponse class now includes a status_code property for easier access to response status codes.
* The lab report parser now supports uploading multiple files in a single request. New modules added for lab account management (`lab_account`), order transactions (`order_transaction`), and compendium search (`compendium`) with comprehensive type support.
* Enhanced lab tests functionality with new optional parameters for improved filtering and appointment booking. New parameters include `lab_account_id` and `lab_slug` for lab test retrieval, `order_transaction_id` for order filtering, `appointment_notes` for phlebotomy appointments, and idempotency support for PSC appointment booking.
* The SDK now supports additional optional parameters for enhanced lab test functionality. New capabilities include lab-specific filtering with `lab_slug` parameter, order transaction filtering, appointment notes, clinical notes for orders, and idempotency support for PSC appointment booking. The `get_psc_appointment_availability` method now requires a `lab` parameter and supports stale data caching.
* The SDK now supports tracking mobile SDK versions through new `vital_ios_sdk_version` and `vital_android_sdk_version` parameters in the `connect_manual_provider` method. Additionally, a new `granted_permissions` parameter allows specifying permissions when connecting manual providers.
* New compendium client available for laboratory test search and conversion workflows. The SDK now supports searching across multiple lab providers and converting test specifications between different laboratory systems. Additional client modules for lab account management and order transactions are also now available.
* The SDK now includes three new client modules for enhanced laboratory operations: CompendiumClient for searching and converting lab tests, LabAccountClient for managing team lab accounts, and OrderTransactionClient for retrieving order transactions and results. Additionally, a new logging system provides configurable debug output for SDK operations.
* The SDK now supports order transaction management with new methods for retrieving transaction details, results, and PDF reports. Over 30 new types have been added for enhanced lab order and compendium functionality, including support for lab accounts and transaction status tracking.
* The SDK now supports insulin injection timeseries data with comprehensive metadata including delivery modes, bolus purposes, and pump source types. Enhanced appointment booking with asynchronous confirmation options and timeout controls. Added support for Sonora Quest as a lab and appointment provider. Introduced derived readiness metrics and recovery readiness scores in sleep data.
* The SDK now supports additional lab providers (Sonora Quest, CRL), Samsung Health as a manual provider, and Tandem Source as a password provider. New enum types have been added for lab account management, order tracking, and insulin injection timeseries. Patient address objects now include an optional access_notes field, and lab results include order transaction information.
* New data types added for compendium search functionality, gender metadata classification, US state management, and enhanced address handling. Sleep data now includes recovery readiness scoring capabilities.
