## 2.2.0 - 2026-03-13
* The SDK now supports HTTP request/response logging for debugging purposes. Configure logging by passing a LogConfig or Logger instance to the client constructor. Lab report parsing now accepts multiple files in a single request instead of just one file. A new SONORA_QUEST option is available in the AppointmentPscLabs enum.
* The SDK now supports additional filtering and configuration options for lab test operations. New optional parameters include lab account filtering, order transaction ID filtering, appointment availability caching controls, idempotency key support for PSC appointments, and clinical notes for orders.
* The SDK now supports mobile SDK version tracking through new `vital_ios_sdk_version` and `vital_android_sdk_version` optional parameters in `connect_manual_provider`. New lab account management capabilities are available through the `lab_account` module, and lab test search functionality is accessible via the new `compendium` module. Order transaction management has been enhanced with new response types and improved metadata handling.
* New client modules available: CompendiumClient for lab test search and conversion, LabAccountClient for lab account management, and OrderTransactionClient for order transaction handling. The SDK now supports configurable logging with optional logging parameter in client constructors.
* The SDK now includes new lab account and order transaction management capabilities. The `LabAccountClient` provides methods to retrieve and filter team lab accounts by status. The `OrderTransactionClient` enables retrieving transaction details, results, and PDF reports. Manual provider linking now supports mobile SDK version headers for improved tracking.
* The SDK now supports lab account management with new types for tracking account status, delegated flows, and business unit configurations. Order transaction functionality has been added to group related orders together. Appointment booking now supports asynchronous confirmation with configurable timeouts. New compendium search capabilities allow provider ID conversion between different labs. Additional enhancements include derived readiness analytics, parsing job failure tracking, clinical notes on orders, and support for Sonora Quest as a lab provider.
* The SDK now supports derived readiness data analysis with new column expressions for sleep scores, recovery metrics, stress scores, and strain data. Samsung Health is now available as a supported provider for health data integration. Lab testing capabilities have been expanded with comprehensive order transaction management, including order tracking and status monitoring. New lab providers Sonora Quest, Apero, and PVerify are now supported. The SDK also includes enhanced data compendium search functionality and US state enumeration support.
