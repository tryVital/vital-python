## 3.0.0 - 2026-03-31
* The SDK now supports Sonora Quest as a PSC lab option in addition to Quest. Use AppointmentPscLabs.SONORA_QUEST when creating appointments with Sonora Quest labs.
* The `parser_create_job` method in the lab report module now accepts a list of files instead of a single file. Replace calls like `client.lab_report.parser_create_job(file=my_file, ...)` with `client.lab_report.parser_create_job(file=[my_file], ...)`. New modules added: `compendium` for lab test search, `order_transaction` for order management, and `lab_account` for lab account operations.
* The SDK now supports additional optional parameters for enhanced lab test and appointment management. New filtering options include lab_account_id, lab_slug, and order_transaction_id parameters. Appointment booking now supports appointment notes, clinical notes, and idempotency keys for better workflow control.
* The SDK now supports additional optional parameters for enhanced lab test management and appointment booking. New parameters include lab filtering options (lab_account_id, lab_slug), appointment notes, clinical notes for orders, transaction ID filtering, and idempotency support for PSC appointment booking.
* The `team_id` parameter has been removed from all bulk operations methods (`list_bulk_ops`, `bulk_import`, `bulk_trigger_historical_pull`, `bulk_export`, and `bulk_pause`). Remove the `team_id` argument from calls to these methods. New optional parameters `vital_ios_sdk_version`, `vital_android_sdk_version`, and `granted_permissions` are now available on the `connect_manual_provider` method.
* The SDK now includes three new client modules: `CompendiumClient` for searching and converting lab tests, `LabAccountClient` for lab account management, and `OrderTransactionClient` for order transaction handling. Enhanced insulin injection tracking with new delivery mode, delivery form, and bolus purpose fields. Order model now supports clinical notes and transaction tracking capabilities.
* New compendium, lab account, and order transaction clients provide access to lab test search, account management, and transaction handling endpoints. All clients include both sync and async implementations with comprehensive error handling and documentation.
* New order transaction management capabilities are now available through the OrderTransactionClient. The SDK supports retrieving transaction details, accessing lab results, and downloading PDF reports with both synchronous and asynchronous interfaces.
* The SDK now supports comprehensive insulin injection monitoring with detailed tracking of delivery modes, forms, and bolus purposes from insulin pumps. Enhanced appointment booking capabilities include asynchronous confirmation with configurable timeout settings. Added support for Sonora Quest as a new lab provider, expanded sleep data with recovery readiness scores, and introduced order transaction tracking with lab account management features.
* The SDK now supports enhanced lab testing workflows with new LabAccountDelegatedFlow and LabAccountStatus enums for managing delegated lab account configurations. New provider integrations include TANDEM_SOURCE and SAMSUNG_HEALTH. Order tracking is improved with additional status values for corrected results and lab processing blocks, plus new OrderOrigin and OrderTransactionStatus enums. Lab compendium search functionality is now available through new SearchCompendiumResponse and related types. Patient addresses now support access notes, and additional payor code providers APERO and PVERIFY are supported.
* New US state enum (UsState) with all 50 state abbreviations is now available. Address models (UsAddress and UserAddress) now support an optional access_notes field for delivery instructions. The SleepColumnExprSleep enum now includes RECOVERY_READINESS_SCORE.
