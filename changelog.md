## 3.0.0 - 2026-03-13
* The SDK now supports configurable HTTP request logging to help with debugging API calls. Lab report parsing has been enhanced to accept multiple files in a single upload operation. The `AppointmentPscLabs` enum now includes support for Sonora Quest appointments.
* The lab tests client now supports additional optional parameters: lab account filtering via `lab_account_id` and `lab_slug` in `get_lab_test()` and `get_markers()`, order transaction filtering via `order_transaction_id` in `get_orders()`, appointment notes in `request_phlebotomy_appointment()`, clinical notes in `create_order()`, and idempotency key support for PSC appointment booking. The `get_psc_appointment_availability()` method now requires a `lab` parameter and supports cached data via `allow_stale`.
* The SDK now supports additional filtering and configuration options for lab tests and appointment booking. New optional parameters include lab account ID and lab slug for lab test creation, order transaction ID filtering, appointment notes, and idempotency support for PSC appointment booking. Manual provider connections now support SDK version tracking, and result metadata includes an optional gender field.
* The `Address` type has been replaced with `UserAddress` in user creation and update methods. Existing code using the `address` parameter will need to import `UserAddress` instead of `Address`. The new type provides the same fields with enhanced validation for user addresses. Additionally, new clients are available: `compendium` for lab test search functionality, `lab_account` for laboratory integrations, and `order_transaction` for order tracking.
* New compendium client with search and convert methods for laboratory test lookup and conversion between different lab providers. New lab account client for managing team laboratory accounts with status filtering.
* New OrderTransactionClient provides methods to retrieve order transaction data and results. Enhanced link API now supports mobile SDK version headers and permission management for manual provider creation.
* The SDK now includes 22 new types for enhanced lab operations and order management. New lab account management types provide access to lab account configurations and status tracking. Order transaction support allows grouping related orders together. Compendium search functionality enables lab test discovery and conversion across providers. Lab report parsing job event types support webhook notifications for parsing status updates. Additional optional fields are available for appointment booking and address specifications.
* The SDK now supports enhanced lab testing workflows with new order transaction tracking, lab account management, and biomarker search capabilities. New provider support has been added for Samsung Health and Sonora Quest. Address types now include optional access notes for delivery instructions.
* New `UsState` enum and `UserAddress` model added for handling user address data. The `UsState` enum provides standardized US state abbreviations with forward compatibility support.
