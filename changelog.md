## 3.0.0 - 2026-03-30
* The SDK now supports Sonora Quest as a PSC lab option. The INSULIN_INJECTION timeseries type has been removed from the available interval timeseries expressions. Enhanced HTTP logging capabilities have been added with automatic redaction of sensitive headers.
* The SDK now supports uploading multiple files for lab report parsing instead of single file uploads. New compendium search functionality is available for medical data lookups. Added lab account management, order transaction tracking, and enhanced insulin injection data fields.
* The SDK now supports additional filtering and configuration options for lab tests and appointments. New optional parameters include lab filtering by account ID and slug, order filtering by transaction ID, appointment notes for phlebotomy requests, idempotency keys for PSC appointment booking, and clinical notes for order creation.
* New optional parameters added to lab test and appointment methods. The `create_lab_test()` method now accepts `lab_account_id` and `lab_slug` parameters. The `get_markers()` method supports `lab_slug` for lab selection. Appointment booking methods now support `appointment_notes` and idempotency keys for PSC appointments. Additional filtering options include `order_transaction_id` for lab test orders and `clinical_notes` for testkit orders.
* The `connect_manual_provider` method now accepts optional `vital_ios_sdk_version`, `vital_android_sdk_version`, and `granted_permissions` parameters for enhanced SDK analytics and permission control. Several methods have been simplified by removing redundant `team_id` and `vital_link_token` parameters that are now inferred from context.
* New compendium search and conversion APIs are now available for matching lab tests across different providers. The SDK adds CompendiumClient with search() and convert() methods, plus LabAccountClient and OrderTransactionClient for enhanced lab workflows. Insulin injection samples now include additional delivery and bolus metadata fields. Order objects support clinical notes, origin tracking, and transaction details.
* The SDK now supports lab test compendium operations, lab account management, and order transaction handling. New clients include `CompendiumClient` for searching and converting lab tests, `LabAccountClient` for managing team lab accounts, and `OrderTransactionClient` for retrieving transaction details and downloading PDF results.
* The SDK now supports order transaction management with the new `RawOrderTransactionClient`. This client provides methods to retrieve transaction details, results, and PDF reports with both synchronous and asynchronous operations. Additionally, 33 new type definitions have been added to support enhanced order transaction workflows, lab account management, and insulin injection data handling.
* The SDK now supports insulin injection data with comprehensive delivery tracking including delivery modes (basal/bolus), forms (standard/extended), and bolus purposes (meal/correction/mixed). Sonora Quest is now available as a lab provider option. Appointment booking and rescheduling now support asynchronous confirmation with configurable timeout settings. New lab account management capabilities and order transaction tracking are available for enhanced workflow management.
* The SDK now supports new lab account management capabilities including lab account status tracking, order transaction management, and provider search functionality. New enum types have been added for lab account delegated flows, order origins, parsing job failure reasons, and search modes. Additionally, the SDK now supports Samsung Health and Tandem Source as data providers, and includes new lab providers Sonora Quest and CRL.
* New `UsState` enum and `UserAddress` model types are now available. The `UsState` enum includes all 50 US state abbreviations with forward-compatible handling of unknown values. The `UserAddress` model provides structured address data including required fields for first line, country, zip, city, and state, plus optional second line and access notes.
