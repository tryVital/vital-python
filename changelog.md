## 3.0.0 - 2026-03-30
* The SDK now includes enhanced HTTP request/response logging capabilities and adds support for Sonora Quest as a PSC lab option. Several unused internal enum types have been removed to streamline the codebase.
* Breaking change: The `parser_create_job` method in `LabReportClient` now accepts a list of files instead of a single file. Update your code to pass `file=[your_file]` instead of `file=your_file`. The method now supports parsing multiple lab report files in a single job.
* The lab tests client now supports additional optional parameters for enhanced filtering and configuration. New capabilities include lab account and slug filtering for lab tests and markers, appointment notes for phlebotomy requests, PSC lab selection for appointment availability, order transaction ID filtering, and clinical notes for order creation. The get_psc_appointment_availability method now requires a lab parameter and supports cached availability data.
* The SDK now supports additional optional parameters for lab test filtering (lab_account_id, lab_slug), order filtering (order_transaction_id), appointment booking with notes (appointment_notes, clinical_notes), and idempotency support for PSC appointments (idempotency_key, idempotency_error). PSC appointment availability queries now require a lab parameter and support cached data via allow_stale.
* New optional parameters `vital_ios_sdk_version`, `vital_android_sdk_version`, and `granted_permissions` are now available on the `connect_manual_provider()` method for enhanced mobile SDK tracking and permission management. The `team_id` parameter has been removed from all bulk operations methods.
* The SDK now includes three new client modules: CompendiumClient for lab test search and conversion, LabAccountClient for lab account management, and OrderTransactionClient for order transaction handling. Insulin injection samples now track additional delivery details including delivery mode, form, and bolus purpose. Orders support clinical notes, origin tracking, and transaction data. The SDK also adds configurable logging support and enhanced type safety improvements.
* New APIs for lab testing workflow management: CompendiumClient for searching and converting lab tests, LabAccountClient for team account management, and OrderTransactionClient for handling lab order transactions. The SDK also adds configurable logging capabilities and improved serialization handling.
* The SDK now includes comprehensive order transaction management with raw API access. New capabilities include retrieving order transactions, downloading lab results as JSON or streaming PDF, and enhanced lab account management. Additional support for insulin injection delivery tracking and readiness metrics has been added.
* The SDK now supports insulin injection data types including delivery modes (basal/bolus), delivery forms (standard/extended), and bolus purposes (meal/correction/mixed). Added support for Sonora Quest lab provider and order transaction tracking. Appointment booking now supports asynchronous confirmation with configurable timeout controls and appointment notes.
* The SDK now supports additional health providers (Samsung Health, Tandem Source) and lab partners (Sonora Quest, CRL). New optional fields are available for address access notes and order transaction tracking. Enhanced order status tracking includes corrected results and lab processing blocks.
* The SDK now includes a `UsState` enum for US state validation and a `UserAddress` model for structured address handling. The `UsState` enum supports all 50 US states with forward compatibility for future additions.
