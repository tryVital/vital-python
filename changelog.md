## 3.0.0 - 2026-03-20
* The lab report parser methods now accept multiple files instead of a single file. Update calls to `parser_create_job()` to pass a list of files: replace `file=my_file` with `file=[my_file]`. The SDK also adds optional HTTP request logging and enhanced response handling capabilities.
* The lab tests client now supports additional optional parameters for enhanced filtering and control. New capabilities include lab account and slug-based filtering, order transaction ID filtering, appointment notes for phlebotomy requests, idempotency support for PSC appointment booking, and clinical notes for order creation.
* New optional parameters added to lab test and appointment methods. Lab test creation now supports `lab_account_id` and `lab_slug` filtering. Appointment booking includes new `appointment_notes` and idempotency key support. Order queries can now filter by `order_transaction_id`. Image content fields now use proper bytes type instead of string.
* **BREAKING CHANGE**: The `create_user` method now requires a `UserAddress` object instead of `Address` for the address parameter. Update your code by replacing `Address(...)` with `UserAddress(...)` when calling `create_user`. The `UserAddress` type has the same fields as the previous `Address` type.
* New CompendiumClient available for searching and converting lab tests across different providers. Access via `client.compendium.search()` and `client.compendium.convert()` methods.
* New OrderTransaction API client with methods to retrieve transaction details, fetch lab results, and download PDF reports. Added LabAccount API client for managing team lab accounts. Manual provider connection now supports optional iOS/Android SDK version tracking and granted permissions specification.
* The SDK now supports lab account management through new ClientFacingLabAccount types, enhanced appointment booking with notes and async confirmation options, and order transaction tracking. New compendium search capabilities include support for additional lab providers like Sonora Quest.
* The SDK now supports advanced lab testing workflows with new response types for order transactions, lab account management, and provider ID conversion. Added derived readiness column expressions for enhanced health metrics querying. New provider integrations include Samsung Health and Tandem Source, plus additional lab providers Sonora Quest and CRL.
* New types added for compendium search functionality: RelatedCandidate, SearchCompendiumResponse, SearchMode, and ResultMetadataGender. Added comprehensive UsState enum and UserAddress model. Enhanced UsAddress with optional access_notes field.
