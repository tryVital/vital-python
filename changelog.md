## 3.0.0 - 2026-03-27
* The SDK now supports optional logging configuration for HTTP requests with automatic redaction of sensitive headers. HTTP response objects now expose a `status_code` property for improved error handling. The lab report parser method now accepts multiple files instead of a single file. A new `SONORA_QUEST` option is available for appointment PSC labs. Note: The deprecated `INSULIN_INJECTION` enum value has been removed from `IntervalTimeseriesExprTimeseries`.
* The SDK now supports additional optional parameters for enhanced lab test functionality. New parameters include lab account filtering, appointment notes, order transaction ID filtering, and idempotency support for PSC appointment booking. The get_psc_appointment_availability method now requires a lab parameter and supports stale data retrieval.
* The SDK now supports additional optional parameters for enhanced lab test functionality, including lab account filtering, appointment notes, PSC lab selection, idempotency keys for appointment booking, and SDK version tracking for manual provider connections. Several Link client methods have been simplified by removing the required vital_link_token parameter. Enhanced insulin injection tracking with delivery mode, form, and bolus purpose fields.
* The `address` parameter in user registration methods now expects a `UserAddress` type instead of `Address`. Update imports from `Address` to `UserAddress` - the field structure remains the same. New capabilities added: compendium search for lab tests, lab account management, and order transaction handling.
* New CompendiumClient and LabAccountClient modules are now available. CompendiumClient provides search() and convert() methods for laboratory test catalog operations, while LabAccountClient offers get_team_lab_accounts() for team laboratory account management. Both clients include sync and async implementations.
* New order transaction management capabilities including methods to retrieve transaction details, results, and PDF reports. Added lab account management functionality for team-level operations. Enhanced manual provider connections with support for SDK version headers and granted permissions.
* The SDK now supports insulin injection data with new enum types for delivery modes and bolus purposes. Appointment booking has been enhanced with configuration options for async confirmation, timeouts, and notes. New lab account management capabilities and compendium search features are available. Additional provider support includes Sonora Quest and insulin pump device sources.
* The SDK now supports lab order transactions for grouping related orders with transaction-level status tracking. New insulin injection timeseries data support includes comprehensive tracking of delivery modes, forms, and bolus purposes. Additional enhancements include lab account management capabilities, support for new lab providers (Sonora Quest and CRL), derived readiness analytics, order origin tracking, and Samsung Health integration.
* This release adds new order status tracking capabilities, expanded provider support, and lab search functionality. New order status values include corrected test results and lab processing blocks. The SDK now supports Tandem Source for diabetes device data and Samsung Health for Android users. New lab compendium search capabilities enable provider ID conversion and mapping. Address models now include optional access_notes for delivery instructions.
