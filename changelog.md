## 3.0.0 - 2026-03-18
* The lab report parser's `parser_create_job` method now accepts multiple files via `List[File]` instead of a single `File`. Existing code must wrap single files in a list: `parser_create_job(file=[my_file], ...)`. The SDK also adds optional HTTP request logging for debugging and expands appointment PSC labs to include Sonora Quest.
* The SDK now supports additional optional parameters for enhanced lab test filtering and appointment booking. New parameters include lab_slug for alternative lab identification, order_transaction_id for order filtering, appointment_notes for phlebotomy appointments, and idempotency support for PSC appointment booking.
* New optional parameters available for enhanced lab test and appointment management. The create_lab_test methods now accept lab_account_id and lab_slug parameters. Appointment booking supports appointment_notes and idempotency keys for PSC appointments. Order creation accepts clinical_notes, and order filtering supports order_transaction_id. Manual provider connections now support mobile SDK version tracking and permission grants.
* The user creation methods now accept `UserAddress` instead of `Address` for the address parameter. Existing code using `Address` must be updated to use `UserAddress` which provides the same fields with improved type safety.
* New CompendiumClient with search() and convert() methods for lab test data operations, and LabAccountClient with get_team_lab_accounts() method for managing team lab accounts. Both clients support sync and async operations.
* New OrderTransactionClient with methods to retrieve transaction details, lab results, and PDF reports. The SDK also adds lab account management capabilities and enhanced mobile SDK version tracking for link operations.
* The SDK now supports lab account management with new `ClientFacingLabAccount` types and delegated flow capabilities. Added compendium search functionality for lab test discovery and provider ID conversion. Enhanced appointment booking with async confirmation options and appointment notes. New webhook events are available for lab report parsing job lifecycle tracking.
* The SDK now supports derived readiness data queries, order transaction management, and Samsung Health provider integration. New types are available for lab account management, enhanced patient address handling with access notes, and expanded search capabilities for biomarker data.
* New `UsState` enum and `UserAddress` model are now available. The `UsState` enum provides all 50 US state abbreviations with forward compatibility for unknown values. The `UserAddress` model captures complete address information including optional second line and access notes fields.
