## 2.2.0 - 2026-03-24
* The SDK now supports configurable request/response logging through new LogConfig and Logger classes. Lab report parsing operations now accept multiple files per job instead of a single file. Added SONORA_QUEST as a new appointment PSC lab option. HTTP response objects now expose a status_code property for easier status checking.
* The SDK now supports enhanced lab test filtering with new `lab_account_id` and `lab_slug` parameters. Appointment booking has been improved with support for appointment notes, lab-specific availability checks, and idempotency keys for PSC appointments. Order management now includes clinical notes and transaction ID filtering capabilities.
* New optional parameters available for lab test creation (lab_account_id, lab_slug), appointment booking (appointment_notes, idempotency_key), and order management (order_transaction_id filter, clinical_notes). Enhanced insulin injection data now includes delivery mode, form, and bolus purpose information. Simplified Link API calls by removing required vital_link_token parameter from several methods.
* The SDK now uses `UserAddress` instead of `Address` for the user creation parameter. New `compendium`, `lab_account`, and `order_transaction` clients are available with additional API endpoints for enhanced functionality.
* New `CompendiumClient` available for searching and converting lab test data with `search()` and `convert()` methods. New `LabAccountClient` added with `get_team_lab_accounts()` method for retrieving team lab account information. Enhanced logging utilities now available for improved debugging support.
* The SDK now supports order transaction management with new methods to retrieve transaction details, results, and PDF reports. Added lab account functionality for team management and enhanced the link client with mobile SDK version tracking and permissions support.
* The SDK now supports enhanced insulin injection tracking with new delivery mode and bolus purpose fields, lab account management capabilities, appointment notes for booking and rescheduling, and compendium search functionality for finding lab tests. Additional improvements include support for Sonora Quest provider and insulin pump device sources.
* The SDK now supports order transactions, allowing you to track grouped orders through their lifecycle using the new `ClientFacingOrderTransaction` model. New lab providers including Sonora Quest are now supported, along with expanded source types for menstrual cycle and sleep data including insulin pump sources. Order events now include status details for enhanced order monitoring.
* The SDK now supports additional health data providers (Tandem Source and Samsung Health) and payor code external providers (Apero and PVerify). New lab testing functionality includes parsing job failure reasons, lab candidate search, and provider ID conversion. Address models now include optional access notes for delivery instructions.
